How do I find LEGO building instructions?

Use the search box above to enter a LEGO set number, set name, theme or release year. Brick Instructions For You currently links to 3,537 published instruction pages with video guides across 55 themes and 10 release years. Each published set page keeps the guide, available verified set details and related-set links together so you can move from finding a set to following its build.

  • Know the set number? Search the number for the fastest route to its instruction page.
  • Browsing instead? Explore sets by theme, year, latest additions or 28-day popularity.
  • Looking for a future set? Upcoming pages are clearly labelled until an instruction video is available.

LEGO instruction questions

How do I find instructions for a LEGO set?

Enter the set number or set name in the search box. You can also browse by theme or release year if you do not know the exact set number.

Can I follow the LEGO instructions as a video?

Yes. Published instruction pages include the matching step-by-step video guide. Where chapter data is available, timestamp links can take you directly to a stage of the build.

Are upcoming LEGO sets included?

Yes. Named upcoming sets with enough confirmed catalogue information can have clearly labelled upcoming pages. They remain distinct from published video guides until the instruction video is available.
