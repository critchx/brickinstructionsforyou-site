The recorded release year for this collection is 2022. Catalogue subtheme labels represented here include Beach, Farm, Fire, Funfair and Great Vehicles, plus 11 more. These figures come from the same current catalogue records used to generate the individual set pages.

To find a particular LEGO City model, match the set number shown on its card or use the site search above. A published-guide page provides the embedded instruction video and any available chapter links and verified set facts; a coming-soon page identifies the model without implying that its video is already published.
