The recorded releases span 2021 to 2027 across 7 different years. Catalogue subtheme labels represented here include Botanical Collection, Formula 1, Gift with Purchase, Houses of the World and Insiders Reward, plus 14 more. These figures come from the same current catalogue records used to generate the individual set pages.

To find a particular LEGO Promotional model, match the set number shown on its card or use the site search above. A published-guide page provides the embedded instruction video and any available chapter links and verified set facts; a coming-soon page identifies the model without implying that its video is already published.

Sets represented on this page include: LEGO 40909 Restaurants of the World: Italy, LEGO 6593417 Mosaic, LEGO 6695501 Giftbox and LEGO 6644894 Reindeer. Each link opens the matching set page, where the set number, full model name, release information and instruction-video status are kept together.
