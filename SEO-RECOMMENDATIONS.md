# SEO recommendations for brickinstructionsforyou.com

These changes belong in the upload script (`Build_Website.py`), which is not in this repository. The live site is the committed `public/` output (Build 142, canonical `https://www.brickinstructionsforyou.com`). Do not hand-edit the generated HTML.

Nothing else on the site should change: no design changes and no content changes beyond the items below.

## robots.txt

- Keep the existing groups: `*`, OAI-SearchBot, Claude-SearchBot, Claude-User, and PerplexityBot.
- Add `Disallow: /search/` to every group.
- Add the same Allow plus `Disallow: /search/` group for GPTBot, Google-Extended, ClaudeBot, anthropic-ai, Bingbot, and Googlebot.
- Point `Sitemap` at `https://www.brickinstructionsforyou.com/sitemap-index.xml`.
- Do not disallow coming-soon set URLs. Crawlers have to fetch the page to see `noindex`.

## Sitemaps

- Replace the single urlset with a sitemap index plus four sitemaps: sets, themes, years, and core pages.
- Keep `/sitemap.xml` working by serving that same index.
- `sitemap-sets.xml`: 3,274 published set pages. Leave out the 819 coming-soon set URLs.
- `sitemap-themes.xml`: 363 `/themes/...` URLs.
- `sitemap-years.xml`: 262 URLs (`/years/`, `/YYYY/`, and `/YYYY/theme/`).
- `sitemap-pages.xml`: 7 core pages:
  - `/`
  - `/popular/`
  - `/latest/`
  - `/2027-rumoured-lego-sets/`
  - `/about/`
  - `/coming-soon/`
  - `/privacy-policy/`
- Put `/2027-rumoured-lego-sets/` in the pages sitemap, not the years sitemap. It is already in the current sitemap.
- The current `public/sitemap.xml` has 4,725 URLs and no `<lastmod>`.
- Set `<lastmod>` from the video `uploadDate` or the page's git commit date. Use the build date only when neither exists.

Sitemap index shape:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap><loc>https://www.brickinstructionsforyou.com/sitemap-sets.xml</loc><lastmod>YYYY-MM-DD</lastmod></sitemap>
  <sitemap><loc>https://www.brickinstructionsforyou.com/sitemap-themes.xml</loc><lastmod>YYYY-MM-DD</lastmod></sitemap>
  <sitemap><loc>https://www.brickinstructionsforyou.com/sitemap-years.xml</loc><lastmod>YYYY-MM-DD</lastmod></sitemap>
  <sitemap><loc>https://www.brickinstructionsforyou.com/sitemap-pages.xml</loc><lastmod>YYYY-MM-DD</lastmod></sitemap>
</sitemapindex>
```

## Coming-soon set pages

- Add `<meta name="robots" content="noindex,follow">` to every set page that has no video yet.
- That is 1,061 set pages on disk:
  - 819 are already in the sitemap. 693 of those are for sets that are already released.
  - 242 are not in the sitemap. Give them the same tag.
- 227 `*-coming-soon` slugs already have this tag. Add it to the rest.
- Remove the tag on the build where a video exists, then add the page to `sitemap-sets.xml` and set `<lastmod>` to the publish date.
- `follow` means crawlers still follow links to themes, years, and related sets.

## Search

- `/search/` already has `<meta name="robots" content="noindex,follow">`. Leave it.
- `public/_headers` already sends `X-Robots-Tag: noindex, follow` for `/search/` and `/search/*`. Leave it.
- The new robots.txt `Disallow: /search/` is the part that still needs adding.

## Crawlable template text

- On all 5,226 HTML pages, stop shipping these literals in the page source:
  - `<h2>${heading}</h2>`
  - `<h2>No LEGO instructions found</h2>`
  - `${set.page_url}`
- Build those nodes with `document.createElement`, or put the markup in a `<template>` and fill it from JavaScript.
- On the homepage only, change the all-caps section headings to normal case and keep them visually uppercase with CSS `text-transform: uppercase`.
- `.results-header h2` already has that rule. `.quick-card h2` does not, so add it there.
- Headings to change:
  - Browse by year
  - Browse by theme
  - Popular instructions
  - Popular LEGO instructions — last 28 days
  - Latest 2026 LEGO instructions
  - Upcoming 2026 LEGO instructions
- Do not change button labels such as "BROWSE YEARS" or "VIEW POPULAR". Those are not headings.
